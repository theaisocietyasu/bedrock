# hackathon_webhook

Posts upcoming hackathons from Hack Club, Euro-Hackathons and Hackalist to a Discord channel. The [feeds](../feeds/README.md) module runs the feeds of kind `hackathons`.

## Files

| File | Holds |
| --- | --- |
| `source.py` | Reads the hackathon listings: config checks and the fetch |

## Surface

- Sub-modules: the `hackathons` feed of `submodules/careers`.
- Routes, jobs, tools and tables: those of [feeds](../feeds/README.md), for feeds of kind `hackathons`.

See [docs/modules/feeds.md](../../docs/modules/feeds.md).
